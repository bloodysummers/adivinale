## ADDED Requirements

### Requirement: Videojuegos content uses subcategory sub-lotes with a total target of 180
`db/seed/words/videojuegos-curated.sql` SHALL contain a curated list of game titles and iconic characters organized in five sub-lotes, deduplicated by normalized title, producing ≤180 rows for category `videojuegos`. Entries SHALL be titles or characters recognizable to a LATAM audience aged 15–50. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Criteria | Limit |
|---|---|---|
| Nintendo clásico | Classic Nintendo franchise titles (Mario, Zelda, Pokémon, etc.) | 35 |
| Títulos 90s/2000s | Top-rated and most-played games from 1990–2009 | 40 |
| Títulos modernos | Top-rated games from 2010–2024 | 40 |
| Franquicias PlayStation/Xbox | Iconic PlayStation and Xbox exclusive/flagship titles | 35 |
| Personajes icónicos | Universally recognized video game characters (Mario, Link, Sonic, etc.) | 30 |

**Language:** Game titles in English as the most commonly known form (e.g. "The Legend of Zelda", "Grand Theft Auto V"). Character names as most commonly used in LATAM. All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 180 deduplicated videojuegos rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤180 INSERT rows for `category_id = 'videojuegos'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
