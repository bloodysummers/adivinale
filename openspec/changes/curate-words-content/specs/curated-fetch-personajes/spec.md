## ADDED Requirements

### Requirement: Personajes content uses occupation sub-lotes with a total target of 175
`db/seed/words/personajes-curated.sql` SHALL contain a curated list of famous people organized in six occupation sub-lotes, deduplicated by name, producing ≤175 rows for category `personajes-famosos`. Entries primarily known as video game characters SHALL be excluded. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Criteria | Limit |
|---|---|---|
| Actores/Actrices | Film and TV actors with strong LATAM recognition | 40 |
| Deportistas | Athletes (soccer, boxing, F1, tennis, basketball, etc.) | 40 |
| Músicos/Artistas | Musicians and music artists | 35 |
| Políticos históricos | Historical politicians and world leaders (widely studied) | 25 |
| Empresarios/Innovadores | Entrepreneurs and innovators with global name recognition | 15 |
| Influencers/Personalidades digitales | Social media personalities known to LATAM 15–50 audience | 20 |

**Language:** Names in Spanish or the most-recognized hispanized form (e.g. "Cristiano Ronaldo", "Albert Einstein"). All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 175 deduplicated personaje rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤175 INSERT rows for `category_id = 'personajes-famosos'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
