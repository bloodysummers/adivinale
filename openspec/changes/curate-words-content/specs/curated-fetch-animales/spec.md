## ADDED Requirements

### Requirement: Animales content uses taxonomy sub-lotes with a total target of 150
`db/seed/words/animales-curated.sql` SHALL contain a curated static list organized in six taxonomy sub-lotes, deduplicated by normalized name, producing ≤150 rows for category `animales`. All entries SHALL be animals known to a LATAM audience aged 15–50, with names in Spanish, ≤40 characters. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Criteria | Limit |
|---|---|---|
| Domésticos/Granja | Common pets and farm animals | 25 |
| Mamíferos salvajes | Globally/regionally known wild mammals | 30 |
| Marinos | Ocean and freshwater animals | 25 |
| Aves | Birds recognizable to LATAM audience | 25 |
| Reptiles/Anfibios | Common reptiles and amphibians | 20 |
| Insectos/Arácnidos | Common insects and arachnids | 25 |

**Language:** All names in Spanish. All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 150 deduplicated animal rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤150 INSERT rows for `category_id = 'animales'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
