## ADDED Requirements

### Requirement: Anime content uses subcategory sub-lotes with a total target of 150
`db/seed/words/anime-curated.sql` SHALL contain a curated list of anime titles and iconic characters organized in five sub-lotes, deduplicated by normalized name, producing ≤150 rows for category `anime`. Entries using non-Latin characters SHALL be skipped. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Criteria | Limit |
|---|---|---|
| Shōnen / Acción | Action/adventure anime series with broad LATAM recognition | 30 |
| Comedia / Slice of Life | Comedy and slice-of-life anime | 25 |
| Drama / Seinen | Drama and seinen anime | 25 |
| Familiar / Ghibli | Family anime and Studio Ghibli films | 25 |
| Personajes icónicos | Iconic anime characters (Goku, Naruto, Pikachu, etc.) | 45 |

**Language:** `text` = Spanish title when a well-known Spanish translation exists, otherwise the most-recognized Latin-alphabet title. `subtext` = Japanese transliteration or English title when different. Entries with kana/kanji in the most-recognized form SHALL be skipped. All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 150 deduplicated anime rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤150 INSERT rows for `category_id = 'anime'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
