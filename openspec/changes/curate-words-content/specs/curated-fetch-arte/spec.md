## ADDED Requirements

### Requirement: Arte content uses subcategory sub-lotes with a total target of 150
`db/seed/words/arte-curated.sql` SHALL contain a curated list of artists and artworks organized in five sub-lotes, deduplicated by normalized text, producing ≤150 rows for category `arte`. Entries SHALL be figures or works recognizable to a LATAM audience with a general secondary education. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Content type | Limit |
|---|---|---|
| Pintores clásicos | Artist names — Renaissance through 19th century painters | 30 |
| Pintores modernos | Artist names — Impressionism through mid-20th century | 30 |
| Pinturas famosas | Artwork titles — universally recognized paintings | 30 |
| Esculturas | Artwork titles — universally recognized sculptures | 25 |
| Contemporáneos | Artist names — late-20th/21st century with high global recognition | 35 |

**Language:** Spanish names for artists when a Spanish form exists; most recognized title for artworks. All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 150 deduplicated arte rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤150 INSERT rows for `category_id = 'arte'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
