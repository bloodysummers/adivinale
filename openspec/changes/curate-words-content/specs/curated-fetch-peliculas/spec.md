## ADDED Requirements

### Requirement: Películas content uses subcategory sub-lotes with a total target of 180
`db/seed/words/peliculas-curated.sql` SHALL contain a curated list of movies organized in six sub-lotes, deduplicated by normalized title, producing ≤180 rows for category `peliculas`. All entries SHALL be movies recognizable to a LATAM audience aged 15–50. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Criteria | Limit |
|---|---|---|
| Clásicos pre-1990 | Pre-1990 films with high global recognition | 25 |
| Décadas 90s | Films from 1990–1999 | 35 |
| Décadas 2000s | Films from 2000–2009 | 35 |
| Décadas 2010–2024 | Films from 2010 onward | 40 |
| Animación | Animated feature films | 25 |
| Superhéroes/Acción | Superhero and action blockbusters | 20 |

**Language:** `text` = Spanish title (e.g. "El Padrino"), `subtext` = English title when different (e.g. "The Godfather"). Entries originally in non-Latin scripts SHALL be skipped. All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude based on LATAM popularity and recognizability criteria. No external API is used.

#### Scenario: SQL file contains at most 180 deduplicated movie rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤180 INSERT rows for `category_id = 'peliculas'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
