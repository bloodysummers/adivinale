## ADDED Requirements

### Requirement: Música content uses subcategory sub-lotes with a total target of 175
`db/seed/words/musica-curated.sql` SHALL contain a curated list of artists and songs organized in five sub-lotes (~50% artist names, ~50% song titles), deduplicated by normalized text, producing ≤175 rows for category `musica`. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Content type | Limit |
|---|---|---|
| Pop internacional | Artist names — global pop acts with strong LATAM recognition | 35 |
| Rock/Metal | Artist names — classic and modern rock/metal acts | 35 |
| Reggaetón/Urbano | Artist names — reggaetón, trap, and urbano LATAM acts | 30 |
| Latinos clásicos | Artist names — classic Latin pop, salsa, bolero, cumbia artists | 35 |
| Canciones icónicas | Song titles — one universally known song per artist/genre | 40 |

**Language:** Artist names and song titles as most commonly known in LATAM (Latin-alphabet only). All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 175 deduplicated música rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤175 INSERT rows for `category_id = 'musica'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
