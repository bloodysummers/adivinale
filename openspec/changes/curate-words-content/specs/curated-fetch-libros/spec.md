## ADDED Requirements

### Requirement: Libros content uses subcategory sub-lotes with a total target of 160
`db/seed/words/libros-curated.sql` SHALL contain a curated list organized in five sub-lotes (~70% book titles, ~30% author names), deduplicated by normalized text, producing ≤160 rows for category `libros`. Entries SHALL be titles or authors recognizable to a LATAM audience aged 15–50 with a general secondary education. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Content type | Limit |
|---|---|---|
| Clásicos universales | Book titles — pre-20th century literature taught globally | 30 |
| Literatura latina | Book titles + author names — Latin American canonical works and authors | 35 |
| Bestsellers modernos | Book titles — post-1980 global bestsellers with strong LATAM presence | 30 |
| Sagas populares | Book series/saga names — fantasy, YA, thriller sagas with broad recognition | 30 |
| Autores icónicos | Author names — authors recognizable by name alone | 35 |

**Language:** Titles use the official Spanish translation when one exists (e.g. "Cien años de soledad"). If no Spanish translation exists, English title is acceptable (e.g. "The Great Gatsby"). Titles in non-Latin scripts are skipped. All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 160 deduplicated libros rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤160 INSERT rows for `category_id = 'libros'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
