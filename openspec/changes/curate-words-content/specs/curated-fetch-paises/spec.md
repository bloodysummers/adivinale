## ADDED Requirements

### Requirement: Países content uses recognizability sub-lotes with a total target of 150
`db/seed/words/paises-curated.sql` SHALL contain a curated list of countries organized in five regional sub-lotes, sorted by recognizability/population within each region, producing ≤150 rows for category `paises`. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Criteria | Limit |
|---|---|---|
| Europa occidental | Western, Southern, and Northern European countries | 30 |
| Américas | Countries of North, Central, and South America | 35 |
| Asia conocida | Most recognized Asian countries (by LATAM audience) | 30 |
| África reconocida | Most recognized African countries (by LATAM audience) | 25 |
| Resto | Oceania + Eastern Europe + Caribbean + other recognizable nations | 30 |

**Language:** Country names in Spanish (e.g. "Alemania", "Francia", "Japón"). All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 150 deduplicated países rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤150 INSERT rows for `category_id = 'paises'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
