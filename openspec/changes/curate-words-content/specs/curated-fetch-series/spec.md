## ADDED Requirements

### Requirement: Series content uses subcategory sub-lotes with a total target of 160
`db/seed/words/series-curated.sql` SHALL contain a curated list of TV shows organized in five sub-lotes, deduplicated by normalized name, producing ≤160 rows for category `series`. All entries SHALL be shows recognizable to a LATAM audience aged 15–50. Sub-lote definitions are read from `db/scripts/config/subcategories.ts`.

Sub-lotes and individual limits:
| Subcategoría | Criteria | Limit |
|---|---|---|
| Drama | Drama series with strong LATAM/global recognition | 40 |
| Comedia | Comedy series | 35 |
| Animadas adultos | Adult animated series (not anime) | 25 |
| Reality/Documental | Reality shows and documentaries | 20 |
| Recientes populares | Popular series from 2018 onward | 40 |

**Language:** `text` = Spanish title when a well-known Spanish translation exists (e.g. "Los Soprano"), otherwise original title. `subtext` = original English title when `text` is in Spanish. All `text` values ≤ 40 characters.

**Source:** Curated list generated by Claude. No external API is used.

#### Scenario: SQL file contains at most 160 deduplicated series rows
- **WHEN** the SQL file is generated
- **THEN** it contains ≤160 INSERT rows for `category_id = 'series'`, all with `text` length ≤ 40 characters and a non-null `subcategory` value
